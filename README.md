# Felicitación interactiva para la abuelita 💗

Página estática (HTML, CSS y JavaScript, sin dependencias ni conexiones externas).
Recorrido: Bienvenida → Carta → Pastel → Ramo de tulipanes y girasoles.

## Abrirla en tu computadora

Abre `index.html` con doble clic en Google Chrome. No necesita servidor ni compilación.

## Publicarla con GitHub Pages

1. Inicia sesión en [github.com](https://github.com) y crea un repositorio nuevo (por ejemplo `felicitacion-abuelita`), público.
2. Sube los cuatro archivos (`index.html`, `styles.css`, `script.js`, `README.md`) a la raíz del repositorio con **Add file → Upload files**.
3. Abre la pestaña **Settings** del repositorio.
4. Entra en **Pages** (menú lateral).
5. En **Build and deployment**, elige **Deploy from a branch**, selecciona la rama `main` y la carpeta `/ (root)`.
6. Pulsa **Save**.
7. Espera uno o dos minutos. Cuando GitHub termine de publicar, aparecerá arriba el enlace público, normalmente `https://TU-USUARIO.github.io/felicitacion-abuelita/`.
8. Abre ese enlace en Google Chrome en un teléfono Android y recorre las cuatro pantallas.

Todas las rutas son relativas, así que funciona bajo la ruta del repositorio.

## Comprobaciones manuales en el teléfono

- La bienvenida muestra globos y el botón se pulsa con comodidad.
- Aparece confeti una sola vez y se abre la carta completa (con desplazamiento vertical).
- "Mira un pastel 🎂" muestra el pastel sin velas y el mensaje de agradecimiento.
- "Mira un regalo 🎁" hace crecer tallos, hojas, tulipanes y girasoles, y al final aparecen envoltorio, destellos y la dedicatoria.
- No hay desplazamiento horizontal; con "reducir animaciones" activado el ramo aparece completo de inmediato.
